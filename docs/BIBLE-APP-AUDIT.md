## 3. P0 - 핵심 누락 기능 (없으면 성경앱으로 불완전)

이 기능들이 없으면 사용자가 주력 성경앱으로 채택하기 어렵다.

### 3.1 구절 검색 (키워드)

| 항목      | 내용                                                                                        |
| --------- | ------------------------------------------------------------------------------------------- |
| 현재 상태 | 없음. 책 → 장 순차 탐색만 가능                                                              |
| 복잡도    | **M** (Medium)                                                                              |
| 영향도    | 매우 높음 - 성경앱의 가장 기본적인 기능                                                     |
| 구현 방향 | MongoDB text index 또는 Atlas Search 활용                                                   |
| 관련 파일 | `server/src/routes/bible.js` (새 검색 API 추가), `client/src/pages/BiblePage.tsx` (검색 UI) |

**구현 세부:**

- 서버: `GET /api/bible/search?q={keyword}&book={bookAbbr}` API 추가
- BibleBook 모델의 chapters 배열에 text index 생성
- 클라이언트: 검색 입력 + 디바운스(300ms) + 결과 리스트 (책/장/절 + 미리보기)
- 결과 클릭 시 해당 구절로 이동

### 3.2 절 복사/공유

| 항목      | 내용                                     |
| --------- | ---------------------------------------- |
| 현재 상태 | 없음                                     |
| 복잡도    | **S** (Small)                            |
| 영향도    | 높음 - 구절 인용/공유는 일상적 사용 패턴 |
| 구현 방향 | Clipboard API + Web Share API            |
| 관련 파일 | `client/src/shared/PassageViewer.tsx`    |

**구현 세부:**

- 구절 롱프레스/선택 시 액션 시트 표시 (복사, 공유, 북마크)
- 복사 포맷: `"구절 텍스트" - 책명 장:절 (번역본)`
- Web Share API (모바일) / Clipboard API (데스크톱) 분기

### 3.3 직접 장/절 이동

| 항목      | 내용                                       |
| --------- | ------------------------------------------ |
| 현재 상태 | 없음. 책 목록 → 장 그리드 → 스크롤만 가능  |
| 복잡도    | **S** (Small)                              |
| 영향도    | 높음 - "요한복음 3:16" 바로 가기 불가      |
| 구현 방향 | 퀵 점프 모달 (책 선택 → 장 입력 → 절 입력) |
| 관련 파일 | `client/src/pages/BiblePage.tsx`           |

**구현 세부:**

- 상단 헤더에 현재 위치 표시 + 터치 시 점프 모달
- 자동완성 책 검색 (한글/영문 약어 모두)
- `창 3:16` 또는 `요 3:16` 같은 단축 입력 파싱

### 3.4 오프라인 성경 텍스트 :white_check_mark:

| 항목      | 내용                                                                                |
| --------- | ----------------------------------------------------------------------------------- |
| 현재 상태 | 완료 - IndexedDB 전체 성경 저장 + 오프라인 fallback                                 |
| 복잡도    | **L** (Large)                                                                       |
| 구현 방향 | idb 라이브러리 + bulk API + 훅 레벨 오프라인 fallback                               |
| 관련 파일 | `client/src/lib/offline-bible.ts`, `client/src/store/offline-store.ts`, 설정 페이지 |

**구현 세부:**

- `idb` 라이브러리로 IndexedDB 래퍼 (books, chapters, meta 스토어)
- `GET /api/bible/bulk` 서버 API로 전체 성경 일괄 다운로드
- `usePassage`, `useBibleBooks`, `useBibleSearch` 훅에 오프라인 fallback 내장
- 설정 페이지에 다운로드/삭제/재다운로드 UI (진행률 표시)
- `useOfflineStore` (Zustand persist)로 다운로드 상태 관리

### 3.5 최근 읽은 위치 기억

| 항목      | 내용                                                      |
| --------- | --------------------------------------------------------- |
| 현재 상태 | 최근 방문 책 3개만 localStorage에 저장. 장/절 위치 미저장 |
| 복잡도    | **S** (Small)                                             |
| 영향도    | 높음 - 앱 재진입 시 이전 읽던 곳으로 바로 갈 수 없음      |
| 구현 방향 | Zustand persist 스토어 + 서버 동기화                      |
| 관련 파일 | 새 `client/src/store/reading-position-store.ts`           |

**구현 세부:**

- 저장 데이터: `{ bookAbbr, chapter, verse, scrollPosition, timestamp }`
- 페이지 떠날 때 자동 저장 (debounce)
- 앱 진입 시 "이어서 읽기" 배너 표시
- 선택적 서버 동기화 (다기기 지원)

### 3.6 온보딩/튜토리얼

| 항목      | 내용                                     |
| --------- | ---------------------------------------- |
| 현재 상태 | 없음. 로그인 후 바로 대시보드            |
| 복잡도    | **M** (Medium)                           |
| 영향도    | 중간 - 신규 사용자 이탈률에 직접 영향    |
| 구현 방향 | 최초 로그인 시 3~4단계 온보딩 플로우     |
| 관련 파일 | 새 `client/src/pages/OnboardingPage.tsx` |

**구현 세부:**

- Step 1: 환영 + 앱 소개
- Step 2: 통독 계획 선택 (1년/6개월/90일)
- Step 3: 알림 설정 (Push 권한 요청)
- Step 4: 첫 읽기 시작
- 완료 후 대시보드로 이동, `isOnboarded` 플래그 저장

### 4.1 구절 하이라이트/색상

| 항목      | 내용                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| 현재 상태 | 없음                                                                            |
| 복잡도    | **M**                                                                           |
| 구현 방향 | 5~6색 팔레트, 구절 선택 → 색상 선택 → 저장                                      |

**구현 세부:**

- Highlight 모델: `{ userId, bookId, chapter, verse, color, createdAt }`
- 구절 터치/클릭 시 컨텍스트 메뉴 (하이라이트, 북마크, 복사)
- 색상: 노랑, 초록, 파랑, 분홍, 보라, 없음(제거)
- 모든 하이라이트 목록 페이지 (색상별 필터)

## 7. 아키텍처/성능 개선사항

### 7.1 서버 TypeScript 전환

| 항목     | 내용                                                    |
| -------- | ------------------------------------------------------- |
| 현재     | Express + JavaScript (타입 없음)                        |
| 문제     | 런타임 에러, 리팩토링 어려움, IDE 지원 부족             |
| 방향     | 점진적 TS 전환 (`.js` → `.ts`, `allowJs: true`부터)     |
| 우선순위 | 중간 - 새 기능 추가 시 TS로 작성, 기존 파일 점진적 전환 |

### 7.2 성경 텍스트 캐싱

| 항목 | 내용                                                       |
| ---- | ---------------------------------------------------------- |
| 현재 | 매 요청마다 MongoDB 조회 (BibleBook의 거대한 nested array) |
| 문제 | 동일 구절 반복 조회, 불필요한 DB 부하                      |
| 방향 | Redis 캐싱 레이어 도입                                     |
| 상세 | 캐시 키: `bible:{abbrev}:{chapter}`, TTL: 24시간           |
| 대안 | 정적 JSON 파일로 CDN 서빙 (성경 텍스트는 불변)             |

### 7.3 전체 텍스트 검색

| 항목 | 내용                                                      |
| ---- | --------------------------------------------------------- |
| 현재 | 검색 기능 자체가 없음                                     |
| 방향 | MongoDB Atlas Search 또는 별도 검색 인덱스                |
| 상세 | 한국어 형태소 분석기 (nori) 적용, 자동완성, 유사 검색     |
| 대안 | 클라이언트 사이드 검색 (오프라인 데이터 활용, FlexSearch) |

### 7.4 CDN 활용

| 항목 | 내용                                                 |
| ---- | ---------------------------------------------------- |
| 현재 | 정적 자산은 Vercel CDN, 성경 데이터는 API 서버       |
| 방향 | 성경 텍스트를 정적 JSON으로 CDN 서빙                 |
| 상세 | 책별 JSON 파일 66개 → CloudFlare R2 또는 Vercel Edge |
| 효과 | 서버 부하 대폭 감소, 응답 속도 향상                  |

### 7.5 에러 모니터링

| 항목 | 내용                                         |
| ---- | -------------------------------------------- |
| 현재 | 서버 console.error + Morgan 로깅만           |
| 방향 | Sentry 도입 (프론트엔드 + 백엔드)            |
| 상세 | 에러 추적, 성능 모니터링, 유저 세션 리플레이 |

### 7.6 API 응답 최적화

| 항목 | 내용                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 현재 | BibleBook 모델이 전체 chapters 배열을 포함하는 거대 문서               |
| 문제 | passage 조회 시 불필요한 데이터 로드 가능성                            |
| 방향 | MongoDB projection으로 필요한 chapter만 반환, 또는 Chapter 별도 컬렉션 |

## 8. 접근성(A11y) 점검

### 현재 상태 분석

| 항목              | 상태               | 설명                                       |
| ----------------- | ------------------ | ------------------------------------------ |
| 키보드 네비게이션 | :x:                | Tab 순서 미정의, 포커스 트랩 없음          |
| aria-label        | :warning:          | 일부 아이콘 버튼에 누락                    |
| 색상 대비         | :warning:          | 다크모드 텍스트 대비 검증 필요             |
| 스크린리더 호환   | :x:                | 구절 번호/본문 구분 불가, 랜드마크 미설정  |
| 포커스 관리       | :x:                | 모달 열림 시 포커스 미이동, 닫힘 시 미복귀 |
| 텍스트 크기       | :white_check_mark: | 4단계 조절 가능 (개선 여지 있음)           |
| 모션 감소         | :x:                | `prefers-reduced-motion` 미적용            |
| 언어 속성         | :warning:          | `<html lang="ko">` 확인 필요               |

### 권장 개선사항

**즉시 적용 가능 (P0/P1 작업 시 함께):**

1. 모든 아이콘 버튼에 `aria-label` 추가
2. 구절 뷰어에 `role="article"`, 구절 번호에 `aria-hidden` 또는 적절한 역할
3. 모달 컴포넌트에 포커스 트랩 + `role="dialog"` + `aria-modal`
4. 메인 영역에 `<main>`, `<nav>`, `<header>` 시맨틱 태그 확인
5. `prefers-reduced-motion` 미디어 쿼리로 애니메이션 비활성화 옵션

**중기 개선:** 6. 전체 앱 Tab 순서 정리 + skip navigation 링크 7. WCAG 2.1 AA 색상 대비 검증 (모든 테마) 8. 스크린리더 전용 읽기 모드 (구절 번호 + 본문 명확 구분) 9. 키보드 단축키 (J/K: 다음/이전 장, B: 북마크, S: 검색)
